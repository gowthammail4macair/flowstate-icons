# Google Cloud icons

Google provides these SVGs in its [Google Cloud product icon library](https://cloud.google.com/icons).
FlowState Studio uses four service-specific icons from the
[legacy console archive](https://services.google.com/fh/files/misc/google-cloud-legacy-icons.zip).
The SVGs are byte-for-byte copies. The downloaded ZIP had SHA-256
`a6d9d7921758042538b462f03cf64614c2cebd96743b3ed63580a769fc7de3e9`.

| FlowState SVG | Original ZIP entry |
| --- | --- |
| `google.cloud.audit-logs.svg` | `cloud_audit_logs/cloud_audit_logs.svg` |
| `google.cloud.cloud-ids.svg` | `cloud_ids/cloud_ids.svg` |
| `google.cloud.network-connectivity-center.svg` | `network_connectivity_center/network_connectivity_center.svg` |
| `google.cloud.private-service-connect.svg` | `private_service_connect/private_service_connect.svg` |

`google.firebase.cloud-messaging.svg` is the original full-color Cloud Messaging product
logomark under `Firebase Product Icons/Product Logomark/SVG/` in the
[Firebase brand asset archive](https://firebase.google.com/static/downloads/brand-guidelines/firebase-brand-assets.zip).
The [Firebase brand guidelines](https://firebase.google.com/brand-guidelines/) describe how to use product logomarks.

The [Google Cloud product icon guide](https://services.google.com/fh/files/misc/google-cloud-product-icons.pdf)
recommends its current category artwork for new diagrams. FlowState maps
[Agent Search](https://docs.cloud.google.com/generative-ai-app-builder/docs/introduction)
(formerly Vertex AI Search) to AI & Machine Learning,
[Migration Center](https://docs.cloud.google.com/migration-center/docs/migration-center-overview)
to Migration, and Workload Identity Federation to Security & Identity using
the corresponding category icons already bundled from draw.io.

Google retains rights in its artwork and trademarks. The SVGs are excluded
from the FlowState Studio source-code license.
